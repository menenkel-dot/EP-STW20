# Kinderhaus St. Wolfgang Elternportal

This is a parent portal web application for Kinderhaus St. Wolfgang, a German childcare center.

## Run Locally

**Prerequisites:**  Node.js

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open your browser to `http://localhost:5000`

## Build for Production

```bash
npm run build
npm run preview
```

See `replit.md` for more details about the project architecture and features.
